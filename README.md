# Platform-X Collector Growth Plan
A plan to help Platform-X collectors keep working, invite good people and do more good work.
- 4 ideas in build order: Collector Profile and Trust Score, Weekly Goals and Steady Work Bonus, Invite and Team Program, Extra Pay for Missing Areas.
- Every reward comes only from approved, good work.
- Live page: https://elayneh.github.io/platform-x-gamification/
